# SHAKWEER NET Web POS — PRO MAX 3.0

نظام إدارة وتشغيل لمحل SHAKWEER NET. النسخة دي مبنية على المشروع المرسل وتم تطويرها **بدون حذف الجداول أو الوظائف القديمة**، مع إضافة وحدات تشغيل كاملة وتحسينات على الواجهة.

## أهم الوحدات
- المبيعات والكاشير + باركود + قارئ كاميرا عند دعم المتصفح.
- خصم وضريبة وطرق دفع: نقدي / Vodafone Cash / OPay / آجل.
- المخزون وحركات الدخول والخروج والتسويات.
- العملاء والديون والتحصيل.
- الصيانة: فتح تذكرة، حالات، تكلفة، مقدم، دفعات وتسليم.
- الخزنة: قبض وصرف، ورديات فتح/قفل، فرق الخزنة.
- الحضور والانصراف وحساب ساعات العمل والأجر بالساعة.
- الموظفون والرواتب والسلف وخصم السلف.
- أعطال الإنترنت: أولوية، حالة، ملاحظات الحل، وقت الحل.
- الطلبات: عميل، هاتف، قيمة، أولوية، موعد تسليم، حالات.
- الباندات: تشغيل/إيقاف مؤقت داخل البرنامج.
- التقارير: تاريخ من/إلى، طباعة، مشاركة WhatsApp/Telegram/Email.
- المستخدمون والصلاحيات وسجل التدقيق.
- نسخة احتياطية SQLite من داخل الإعدادات.

## التشغيل على Windows
شغّل `scripts\\install_windows.bat` مرة واحدة ثم `scripts\\run_windows.bat`.

أو من داخل مجلد المشروع:
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
ثم افتح `http://127.0.0.1:8000`.

الحساب الافتراضي عند إنشاء قاعدة جديدة:
- admin / admin123
- cashier / 123456

**غيّر كلمات المرور قبل الاستخدام الفعلي.**

## ملاحظة مهمة عن الباندات
إيقاف الباند من شاشة البرنامج يغيّر حالة الباند في النظام فقط. التنفيذ الفعلي على MikroTik/RADIUS يحتاج بيانات اتصال وواجهة API/RouterOS، ولم يتم اختراع اتصال غير موجود حتى لا يؤثر على الشبكة.

## PostgreSQL
راجع `POSTGRES_SETUP_AR.md`. يتم اختيار قاعدة البيانات من `DATABASE_URL`.
